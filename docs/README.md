# Documentation

This directory contains result summaries and artifact-review documentation. Reviewers should start at the repository-root `ARTIFACT.md`.

| File or directory | Contents |
|---|---|
| `INSTALLATION.md` | System and hardware requirements, Docker setup, RaceLoom runtime acquisition and verification. |
| `REPRODUCTION.md` | Canonical execution of the principal matrix and supplementary group. |
| `VALIDATION.md` | Independent checkers, classifications, test suites, and exit codes. |
| `RESULTS.md` | Verified scientific results of the reproduction. |
| `artifact_review.md` | Reviewer-focused setup and smoke-test guide. |
| `benchmark_runtimes_exact.tsv` | Machine-readable exact per-run runtime table. |
| `final_4x4_matrix.md` | Human-readable B1--B4 result matrix. |
| `final_4x4_matrix.tsv` | Machine-readable B1--B4 result matrix. |
| `references.md` | RaceLoom artifact links, source links, and repository references. |
| `reproduce_paper_numbers.md` | Guide for reproducing paper numbers from sanitized validation logs. |
| `runtime_summary.md` | Runtime summaries for the benchmark sets. |
| `synthetic_s1_s4_matrix.md` | Human-readable S1--S4 synthetic result matrix. |
| `synthetic_s1_s4_matrix.tsv` | Machine-readable S1--S4 synthetic result matrix. |
| `tested_configurations.md` | Systems and configurations used for validation and smoke testing. |
| `validation_logs/README.md` | Sanitized validation logs used by the reproduction script. |
